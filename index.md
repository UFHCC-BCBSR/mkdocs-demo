# Welcome

This site was built with [MkDocs](https://www.mkdocs.org) using the [Material theme](https://squidfunk.github.io/mkdocs-material/). It is designed as a reusable template — anyone in the org can copy it and build their own documentation site with no command line experience required.

---

## How this site works

Every page on this site is a simple markdown file (`.md`) stored in a GitHub repository. When a file is edited and saved — including directly on GitHub.com — the site automatically rebuilds and updates within a couple of minutes.

---

## Getting started

If you are here to **use this template** for your own site, start with the How-To Guides in the left menu. We recommend reading them in order:

1. **Site Structure & Navigation** — how to organize your pages and update the menu
2. **Adding Images** — how to upload and display images
3. **Embedding Video** — how to embed YouTube videos

If you just need to **edit content**, navigate to any page, find the corresponding `.md` file in the `docs/` folder on GitHub.com, click the ✏️ pencil icon, make your changes, and commit.
